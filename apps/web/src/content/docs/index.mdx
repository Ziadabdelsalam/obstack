# Start here

Observability for AI software. obstack joins your API, agents, LLM calls and
infrastructure into a single correlated trace.

Point your existing OpenTelemetry at your obstack — where the AI layer and the
infra layer finally meet.

## Where to go next

- **[Quickstart](/docs/quickstart)** — get a key, send a trace, and see it. Start
  here if you have never sent obstack anything.
- **[Self-hosting](/docs/self-hosting/docker-compose)** — run the whole stack
  yourself, with Docker Compose or the [Helm chart](/docs/self-hosting/helm-chart).
- **[SDKs](/docs/sdks/typescript)** — two lines of setup for
  [TypeScript](/docs/sdks/typescript) or [Python](/docs/sdks/python), or
  [bring your own OpenTelemetry](/docs/sdks/bring-your-own-otel) and write no
  obstack code at all.

Everything obstack does not do is written down too, on one page:
[what obstack does not do](/docs/what-obstack-does-not-do).
