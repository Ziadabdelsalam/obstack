- **(a) Mechanism.** The SDKs implement their own thin instrumentations emitting the D8 span-attribute set directly. NO upstream GenAI contrib instrumentation packages (they emit the event form ingest deliberately does not read, or foreign conventions). Hook machinery IS the established libraries: Python `opentelemetry-instrumentation` `BaseInstrumentor` + wrapt patching `openai` `chat.completions.create` (sync+async) and `anthropic` `messages.create` (sync+async); JS `@opentelemetry/instrumentation` `InstrumentationBase` (require-in-the-middle) patching the same two client surfaces.
- **(b) JS module-system honesty.** CJS patching is what is proven; the TS sample compiles to CJS. Pure-ESM patching of `openai`/`@anthropic-ai/sdk` is NOT claimed this sprint (docs state it; the Vercel-AI path needs no patching and works under ESM regardless). If the `ai` package resists CJS `require`, the sample loads it via dynamic `import()` — acceptable, it is app code.
- **Vercel-AI**: covered via its built-in `experimental_telemetry` (the sample enables it per call) + an obstack `SpanProcessor` registered by `init()` that, in `onEnd`, maps the innermost provider-call span's `ai.*` attributes (`ai.generateText.doGenerate`) to the D8 `gen_ai.*` names on the same span (mutation before export). Exact upstream literals are pinned in a red-then-green unit test against the installed `ai` version, not assumed.
- **(c) api layer: the two-line init owns it** — a sample adding instrumentation calls would break the exit clause. Python: `init()` calls `FastAPIInstrumentor().instrument()` globally when the fastapi instrumentation is importable (optional extra `obstack-py[fastapi]`, the sample installs it); init before app creation, documented. JS: `init()` always registers `@opentelemetry/instrumentation-http` (hard dep — tiny, universal; plain `node:http` server spans carry `http.request.method`, which classifies api). Both inits `setdefault` `OTEL_SEMCONV_STABILITY_OPT_IN=http` — standard OTel env, overridable; without it FastAPI emits legacy `http.method` and the api layer silently dies (demo/compose precedent).
- **(d) Fakes SANCTIONED**: the REAL provider client with `base_url` pointed at a deterministic OpenAI-compatible endpoint served by the sample app itself (no extra container; mirrors the demo's self-call pattern). Fake reports model `gpt-4o-mini` (priced — keeps cost>0 alive end to end). No API key anywhere.

JS: Vercel-AI AND OpenAI e2e in T4 (two llm spans in the one trace — extra llm spans do not break the four-layer claim); Anthropic unit-level. **Streaming calls pass through UNinstrumented this sprint** — a gen_ai span with zero tokens misprices to $0; absence is honest.
